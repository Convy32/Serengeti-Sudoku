# Serengeti Sudoku
A desktop based Sudoku game with infinite levels. No network required
![IMG](/background.png)

## Levels
Utilising an puzzle generator online, we have varying levels, with harder levels receiving less hints
### Easy
All assists available
### Medium
Only Check All hints are available
### Hard
Only check puzzle is available, with no hints given
### Hardcore
Only check the puzzle once. Any incorrect cell is game over!

![IMG](/gameselectbox.png)

## Space Theme
With the universe being possibly infinite, Serengeti Sudoku utilises a space theme throughout the game. This includes a night sky background, futuristic fonts, and others.
